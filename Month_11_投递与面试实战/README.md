# Month 11：投递与面试实战

> **主题：** 海投 + 面试实战 + 复盘迭代，边面试边补漏，持续开源维持活跃度。
> **前置：** 完成 M10（简历、内推、面试四块就位）。
> **月度目标：** 投递 20+ 家，参加多轮真实面试并系统性复盘，边面边补短板，持续产出开源。

## 月度里程碑

- ✅ 投递 20+ 家目标公司（NVIDIA + 头部 AI infra）。
- ✅ 完成多轮真实面试（初面/技术面），每次面试后复盘记录。
- ✅ 根据面试反馈针对性补漏（八股/算法/项目/设计）。
- ✅ 面试空档持续开源，保持 GitHub 活跃度与 PR 产出。
